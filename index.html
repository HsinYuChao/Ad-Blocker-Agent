Ad Blocker Agent

Fitts' Law Pointing Experiment

This interactive experiment transforms the traditional Fitts' Law pointing task into a realistic computer-use scenario. You play the role of an Ad Blocker Agent and must quickly close simulated malicious pop-up advertisements by clicking the red “X” button.

Scenario

Closing pop-up windows is a common computer interaction that can become frustrating when the close button is small or difficult to reach. The Ad Blocker Agent scenario models this everyday task: malicious advertisement pop-ups continuously appear, and the user must locate and click the “X” in the upper-right corner.

The repeated interaction provides a natural context for measuring pointing performance while systematically varying target distance (A) and target width (W).

Innovation

The experiment applies Fitts' Law to a familiar pop-up interaction rather than presenting an abstract pointing task. The close button is always positioned at the upper-right corner of the pop-up, while the pop-up size changes with the target width.

This design also explores the relationship between target boundaries and the Infinite Edge Effect. A target placed at the edge or corner of a display can be easier to acquire because the screen boundary prevents the cursor from overshooting. Small pop-up windows generally do not receive the same benefit, which raises the design question: could a small window boundary provide some form of interaction assistance without simply enlarging the close button?

Application

This experiment investigates a broader HCI problem: frequently accessed small controls can require unnecessary pointing precision and effort. The design could be extended to notifications, dialogs, floating tools, and other temporary interfaces that require users to repeatedly locate and close small controls.

A possible future design is a subtle boundary-based interaction constraint, such as cursor resistance near the edge of a small pop-up window. The goal would be to guide the cursor toward frequently used controls while keeping the visible target size unchanged.

Experiment & Data Analysis

The experiment contains 9 trials. Each trial requires 11 successful clicks; the first click is excluded because its travel distance differs from the remaining movements. The remaining 10 clicks provide valid movement-time measurements for each A/W condition.

The collected data are analyzed using Index of Difficulty (ID) as the independent variable and Movement Time (MT) as the dependent variable.

ID = log₂(A / W + 1)

The Fitts' Law linear model is:

MT = a + b × ID

Example analysis generated from the demo-video data. Linear regression produced a = 335.232, b = 146.18, with R² = 0.9416.

How to Play

  • Click the red X located at the upper-right corner of each popup.
  • There are 9 trials. Each trial requires 11 successful clicks.
  • The first click of each trial is excluded from the analysis. Therefore, each trial produces 10 valid movement-time measurements.
  • Move the mouse directly to the red X and click as quickly and accurately as possible.
